Search my Google Drive for: $ARGUMENTS

Use the Google Drive connector tools (load them with ToolSearch if deferred). Search by topic
keywords and by likely file names. Report a table: file name, type, owner, last modified, link,
and a one-line summary of what it contains (read Docs/Sheets/Slides; skim PDFs). Group by
folder. Flag the 3 most useful files for a report and anything that looks outdated or duplicated.
Read only — do not move, share, rename or trash anything.
